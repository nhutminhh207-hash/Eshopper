# Use Case nền — Anh Tú tiếp tục tổng hợp

| Actor | Use Case | Chủ module |
|---|---|---|
| Khách | Xem/tìm/lọc/chi tiết sản phẩm; đăng ký/đăng nhập | Nhựt; Kiều |
| User | Thêm/sửa/xóa giỏ; đặt COD; xem đơn cá nhân; hủy pending của mình | Nhựt; Anh Tú; Kiều |
| Admin | CRUD danh mục; CRUD sản phẩm/biến thể; xem và xử lý đơn | Châu; Danh; Kiều |

Mọi module có validation/quyền máy chủ. Checkout cần giỏ không rỗng, đủ kho, token phiên đúng; hủy cần trạng thái hợp lệ và hoàn kho một lần. Sơ đồ UseCase.drawio và đặc tả cuối do Anh Tú tổng hợp từ phần đã triển khai.
